# POS NURU · iPad PWA

เว็บไซต์ติดตั้ง: https://actiara26.github.io/POS-NURU/

คู่มือภาษาไทย: [ติดตั้ง ลงข้อมูล สำรอง และอัปเดตบน iPad](GUIDE_IPAD_TH.md) หรือ [อ่านแบบเว็บ](https://actiara26.github.io/POS-NURU/guide.html)

เปิดลิงก์เว็บไซต์ด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดจากไอคอน → ตั้ง PIN เจ้าของร้าน

repository นี้มีเฉพาะไฟล์โปรแกรมที่สร้างแล้ว ไม่มีฐานข้อมูลร้านหรือ PIN เริ่มต้น ข้อมูลบันทึกใน iPad เครื่องเดียว ต้องส่งออกไฟล์สำรองเก็บส่วนตัวนอกเครื่องทุกวัน ห้ามอัปโหลดไฟล์ `.sqlite` ของร้านเข้า repository นี้

รุ่นนี้ยังไม่ส่ง Sheets, Drive หรือ Telegram อัตโนมัติ และต้องทดสอบการติดตั้ง การทำงานออฟไลน์ การส่งออก/กู้คืน และเครื่องพิมพ์บน iPad จริงก่อนใช้รับเงินจริง
